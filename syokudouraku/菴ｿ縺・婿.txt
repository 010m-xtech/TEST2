■ 名産地MAP メニューの変え方

さわるのは、この「menu」フォルダの中だけです。
（index.html・img・system フォルダは さわらないでください）

  syokudouraku/
    index.html   … アプリ本体（さわらない）
    img/         … 47都道府県の街の絵（さわらない）
    system/      … 地図や街のデータ（さわらない）
    menu/        … ★ ここだけ
      menu.js    … メニューの文章
      ○○.webp   … メニューの写真
      使い方.txt  … この説明


■ 写真を入れかえる
1. 新しい写真をこの menu フォルダにアップロードする
   （ファイル名は 半角英数字がおすすめ。例：aichi-ebi.jpg）
   jpg・png・webp どれでもOK。横長（4:3）がきれいに見えます。
2. menu.js の image: "○○" を、そのファイル名に書きかえる
   例） image: "aichi-ebi.jpg",

■ 文章を入れかえる
menu.js の " " の中を書きかえるだけです。
  name   … メニュー名
  from   … 産地・作り手
  poem   … 写真の上の縦書きの一言（\n で改行）
  story  … 紹介文
  point  … こだわり（料理は「素材のこだわり」として出ます）
  menu   … 黒い札の言葉
いらない項目は、その1行ごと消してOKです。

■ 県やメニューを増やす
menu.js の中の { から } までのかたまりをコピーして、下に貼りつけて書きかえます。
県を増やすときは "愛知県": [ ... ], のかたまりごとコピーして県名を変えます。
メニューを登録した県は、地図で赤くなります。
  kind: "sake" … 「酒」マーク
  kind: "fish"（魚介）/ "meat"（肉）/ "veg"（野菜）/ "rice"（米）/ "fruit"（果物）/ "other" … 「食」マーク

■ 注意
・" と , を消してしまうと動かなくなります。
  画面の下に赤い文字が出たら、最後に書きかえた所を見直してください。
・GitHub では、menu.js が表示されないときは menu.txt を menu.js という名前に変えてアップロードしてください。
