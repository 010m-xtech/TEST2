■ 名産地MAP メニューの変え方

さわるのは「menu.js」と「image」フォルダだけです。

  syokudouraku/
    index.html   … アプリ本体（さわらない）
    menu.js      … ★ メニューの文章
    image/       … ★ メニューの写真
    system/      … 地図・街の絵47枚・データ（さわらない）


■ しくみ
menu.js には、47都道府県すべてに「お酒」と「料理」の入れ物が用意してあります。
name（メニュー名）を書いた所だけがアプリに表示されます。
  ・書いた県 … 地図で赤くなり、街に「酒」「食」のマークが出ます
  ・空の所   … 表示されません（ほかの項目も、空なら出ません）
消したいときは、name を "" に戻せば表示されなくなります。


■ 書き方（例：北海道の料理）
    { // ── 料理 ──
      kind: "food",
      name:  "ホタテの浜焼き",
      from:  "北海道 オホーツク産",
      image: "hokkaido-hotate.jpg",
      story: "紹介文をここに書きます。",
      point: "素材のこだわりをここに書きます。"
    }

  name   … メニュー名（★ これを書くと表示されます）
  from   … 産地・作り手
  image  … 写真のファイル名（image フォルダに入れた名前をそのまま）
  story  … 紹介文
  point  … お酒は「こだわり」、料理は「素材のこだわり」として出ます



■ お酒の「種類」と「味」
お酒には、次の2つも書けます。メニュー一覧のタブと、色の札になります。
  type:  "日本酒",   … 種類：ビール・日本酒・焼酎・ワイン・サワー・その他
  taste: "すっきり", … 味：すっきり（緑）・華やか（桃色）・まろやか（黄）・コク（茶）
空のままでも表示されます（タブや札が出ないだけです）。

■ 並び順
地図で金色にした県（特におすすめ）のメニューが、一覧のいちばん上に並び、
「特におすすめ」の札が付きます。金色の県は menu.js の下の featured で決めます。

■ 写真を入れる
1. 写真を image フォルダにアップロードする
   （ファイル名は半角英数字がおすすめ。jpg・png・webp どれでもOK。横長 4:3 がきれい）
2. menu.js の image: "" の中に、そのファイル名を書く


■ 注意
・" と , を消すと動かなくなります。
  画面の下に赤い文字が出たら、最後に書きかえた所を見直してください。
・menu.js がダウンロードできないときは、menu.txt を menu.js に名前を変えて使ってください。
